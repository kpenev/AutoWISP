autowisp.tests.test_diagnostic_expressions module

Class Inheritance Diagram

Tests for the diagnostic expression library stored in a project.

The library is read and written through autowisp.diagnostics.expression_library, against a throwaway project database. What an expression means is tested where those rules live, in the expression layer’s own tests; here it is only what gets stored, and that references survive a rename.

The management form is tested here too, for the one check it makes itself rather than delegating: that a name is a slug and is not already taken.
