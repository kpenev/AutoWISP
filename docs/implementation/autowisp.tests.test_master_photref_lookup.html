autowisp.tests.test_master_photref_lookup module

Class Inheritance Diagram

Tests for fitting new images against the master their photref built.

The engine gives each fit_magnitudes batch the master photometric reference built from the batch’s single photometric reference, found through the progress of the batch that built it: the images of that progress are bound to the reference. A reference is not registered if its masters would be named like those of another.

The project is the one of test_photref_binding, with more single photometric references next to its ref.
