TFA on lightcurves collecting points from two channels of each frame.

class autowisp.tests.test_tfa_multi_channel.TestTFAMultiChannel(methodName='runTest')[source]

Bases: SyntheticLightCurveTestCase

TFA with the default observation id on two-channel lightcurves.

Both channels of a frame share its frame number, so only the channel tells their points apart. Two targets are corrected: an exact combination of the templates, and one of the templates itself, which TFA must fit without its own template. Template 1 and both targets lack one (frame, channel) point the other templates have.
