autowisp.tests.test_custom_group_values module

Class Inheritance Diagram

Tests for evaluating quantities over a photref group’s members.

A photref group is given as its members, (image, channel) pairs that may span sessions, and each member is one point, with a quantity’s slot bound to that member’s own channel.

The fixture is one group over two nights, mixing what has to be told apart: an image that is a member in both G0 and G1; one that is a member only in G1 but has a G0 value too, which must not be read; a non-member on the first night, whose outlying values would shift any aggregate they leaked into; a member on the second night; and a member with nothing recorded in its channel.
