autowisp.multiprocessing_util._enable_faulthandler(stream)[source]

Point faulthandler at stream so a fatal signal self-reports.

A segfault / abort / FPE produces no Python exception, so a worker that dies of one is “silent” and – because the pool executor collapses every pending future to the same BrokenProcessPool and discards which worker died – otherwise unattributable. With faulthandler enabled against the worker’s redirected stderr, the faulting worker dumps a native traceback into its own log before dying; workers the executor merely terminate()``s (``SIGTERM) dump nothing, so the log carrying a dump singles out the culprit. Also arms SIGUSR1 (POSIX) so a hung worker can be prodded to dump where it is stuck.

Best-effort: silently does nothing where it cannot attach (e.g. a captured stderr with no real fileno); never fails bootstrap.

Parameters:

stream – The (already redirected) stderr file object to dump to.

Returns:

None
