class autowisp.magnitude_fitting.iterative_refit.MagnitudeFitting(configuration, *, start_status, mark_start, mark_end)[source]

Bases: object

Magnitude fitting of one batch of DR files.

With an existing master photometric reference configured, every image is fit once against it. Otherwise the images are fit and the master re-derived from them, pass after pass, until it converges; images on the exclusion list are fit too, but kept out of the masters.

_next_reference(magfit_stat_collector, old_reference, master_inputs)[source]

Return the reference for the next pass, or None if this pass was last.

The master built from the pass just completed is saved only if another pass is fit against it: once it agrees with the reference that pass used, or the iterations run out, that reference is final and the new master, used for nothing, is discarded. A pass against the single photometric reference is never the last, so the final master is always one that images were fit against.

Parameters:

  • magfit_stat_collector (MasterPhotrefCollector) – The object used by the magnitude fitting processes to generate the magnitude fitting statistics.

  • old_reference (dict) – The photometric reference used for the last magnitude fitting iteration.

  • master_inputs – See _refit().

Returns:

Fit and re-derive the master photometric reference until it converges.

Parameters:

  • fit_dr_fnames ([str]) – The DR files to fit and build the masters from.

  • excluded_dr_fnames ([str]) – DR files to fit but leave out of the masters. Each pass still marks their progress along with the rest, so an interrupted run leaves the whole batch at one status.

_refuse_clash()[source]

Raise if a file this pass would write exists already.

Only the pass itself writes its files, and cleaning up an interrupted run deletes the partial ones, so a file there can only belong to another master: one built from a single photometric reference the file name formats do not tell apart from this one, or one built earlier from this reference. Either way it is not overwritten.
